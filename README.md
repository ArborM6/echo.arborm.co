## 删号流程验证

`npm test`（Node >= 22.6）验证受理状态 202、确认状态 204、网络失败、限流、超时和网页 fallback；测试使用模拟响应，不发送真实邮件或删除账号。
`npm run build` 生成生产网站。Vercel 构建环境的 `VITE_API_BASE_URL` 必须指向后端 HTTPS 地址（当前为 `https://echo-api.arborm.co`）。
申请失败时保留表单供重试；成功提示保持统一，不透露邮箱是否注册。真实邮件投递与账号清理还需使用获准删除的专用测试账号进行联调。
